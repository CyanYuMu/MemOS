# Dashboard 同步与 Pi Chat 整合

参考：[新版 参考控制台](https://memos-dashboard.openmem.net/cn/quickstart/)，观察于 2026-10-31。真实 Chrome 的观察通过 SuperDuck 完成，公开静态资产只下载分析，保存在任务的 `dashboard-reference/`。

## 整合方式

聊天直接使用当前 React 应用中的账号、项目和 Pi SSE。控制台与聊天共用 Sidebar，手机上通过同一个导航抽屉访问。聊天区保持全高三栏与专用指引工具栏；快速开始增加可用的对话入口。不是另起一个独立站点。

## 同步范围

| 来源变化 | 本项目采用方式 |
| --- | --- |
| 灰色侧栏、白色选中导航、浅紫渐变内容区 | 同步公共壳层，与聊天画布一致 |
| 紫色选中页签、轻量边线、白色表头 | 复用现有 Tabs、PageHeader、Panel、Table，同步视觉与窄屏布局 |
| 快速开始接入选择与步骤卡 | 保留 Hermes 插件、Hermes MCP、Agent 配置提示等现有内容；使用共用页签与真实接口 |
| 模型与记忆列表 | 同步表格和操作布局；数据仍来自当前后端 |
| 手机导航 | 共用项目选择与账号菜单，导航抽屉支持关闭及焦点恢复 |

## 保留已有删除决定

不恢复源码注释与提交历史中明确删除的全局顶栏、免费额度/购买宣传、Agent/代码两层选择器、通用 MCP 快速开始页签、模型参数及未实现的详情按钮、列表中的画像模板 ID。知识库、画像模板等禁用入口保持原状态。远端静态模型名单、配额数值和密钥不会复制进产品。

设计参数：灰色画布 `#f0f2f5`，白色面板 `#ffffff`，浅紫顶部 `#f5f5ff`，主色 `#4044ed`，正文沿用现有中文无衬线栈，辅助代码使用等宽字体。沿用本项目品牌与深色主题。

验证覆盖控制台与聊天双向导航、项目切换、账号菜单、页签键盘操作、原有删减项、320/390/768/1440px 视口，以及前端构建与控制面打包。
