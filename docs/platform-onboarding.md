# 平台 Web 操作指引

主线为个人空间 → Quickstart → API Key → 对话 → 记忆详情和版本 → 调用日志。Agent/代码示例继续显示在Quickstart，不属于任务或完成门槛。

- 全局Provider按账号和当前项目读取后端进度；Sidebar提供继续/重播入口，Quickstart提供六步清单。新账号只在自己的个人空间和Quickstart自动欢迎；旧账号迁移后不弹欢迎。普通用户预览与正常视角使用相同的引导入口和进度，切换视角不重置任务。当前管理员空间被预览隐藏时，只在预览中回退到可用的成员个人空间；退出后恢复原选择，不提交项目切换。
- 跨路由高亮复用driver.js按需加载，使用原有主题和字体。目标未挂载时保留可操作面板；打开密钥弹窗或记忆侧栏时让出遮罩，关闭后恢复。支持Esc退出、窄屏与减少动画。
- 密钥必须由用户在原页面明确创建。是否进入聊天根据真实chat state决定；没有可用Key、只读空间或服务不可用时不提前完成。示例和引导不展示真实密钥，不向聊天输入框注入Key。
- Chat在平台步骤中以嵌入方式复用原有引导，省去重复欢迎。写入按既有真实事件判断，召回为空不能完成；结束后前往记忆列表。服务端保存阶段和会话ID，恢复仅选择原会话，不自动发送消息。
- 记忆步骤要求实际加载详情并打开Versions页签，再进入日志认知步骤；不要求编辑或删除用户记忆。
- “稍后再说”保存检查点；显式重播只重置本项目引导关联，不删除对话或记忆。进度写入串行执行，服务端CAS防止旧版本覆盖；账号/空间切换后的迟到响应不导航到旧步骤。

契约源：后端 `api/openapi.onboarding.yaml`，GET/PUT `/api/auth/onboarding`。`status/revision`是账号级，`step/chat`是账号＋项目级；`chat`仅含stage/first/second会话关联，不存表单或消息。后端核对真实账号和项目权限、会话归属。进度不是记忆成功审计。

验证：`pnpm verify`及i18n脚本。后端有SQLite重开持久化、迁移、CAS、归属和HTTP契约测试。真实部署浏览器检查与模型验收分别记录，不以组件测试代替。
