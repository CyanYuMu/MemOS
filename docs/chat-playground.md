# Pi Agent 聊天体验

本页描述聊天界面的交互。`/cn/chat` 沿用控制台项目、导航、账号、语言与主题：中间展示对话，右侧展示 MemCube 日志；窄屏使用导航和日志抽屉。

## 对话与指引

- 同一账号和项目可以新建独立对话、切换历史；项目记忆共享，模型上下文、队列和消息历史隔离。旧固定会话保留，通过后端会话接口读取，列表查询不隐式创建会话。
- 发送、排队、停止、重试、历史分页与 SSE 重连由 `ChatSession` 接收真实状态。执行事件绑定实际受理消息，切换对话不把迟到事件归到新会话。
- 首次体验提供欢迎、偏好表单与 Driver.js 分步指引，串联实际会话发送和记忆读取；支持跳过和重看。偏好输入框保留最小宽高，窄屏随容器收缩。
- 初始建议用于填写草稿；回答后的参考问题由模型动态生成。点赞／点踩和点踩意见由后端持久化，复制仍取完整回答。
- 模型生成标题只更新历史列表元数据，不改变会话 ID、目录或消息归属。

## 思考、快照与日志

- 思考过程在原位置展开，正文和工具结果在同一区域滚动；不打开全局弹窗，不提供重复的向下展开按钮。
- 用户消息中的记忆快照在消息下方展开卡片，首屏 6 张、每次追加 6 张；桌面三列，较窄窗口自动减少列数。
- 思考与回答的有效记忆引用显示编号；编号只关联对应轮次快照，点击查看该历史实体。未知引用不伪造跳转，代码和普通链接不误识别成记忆引用。
- 卡片保留当时的类型、标签、正文、状态、时间、版本及真实检索分数。未评分的画像、缺失的旧快照明确区分，不查询当前记忆补造历史。
- 日志按实际事件展示检索、写入受理、提取处理中和记忆变化，时间线每条摘要可展开。对话写入详情与完整记忆详情分开，异步受理不等于新增成功，无变化不计作更新。
- “所有记忆”跳转 `/cn/memoryList`；记忆列表中的信息与版本使用右侧详情栏。聊天中的历史实体仍使用独立详情，避免与当前记忆混淆。
- 内容由后端真实调用和持久事件提供；不伪造时间、分数、完成状态或丢失的实体字段。

## 展示与验收

- Markdown 支持表格、公式、代码块及复制；聊天、原始工具 JSON 与接入示例共用语法配色，代码原文保持不变。
- 使用 HugeGraph 标识、中英字典及蓝灰暗色主题；暗色日志的顶部装饰图渐隐至面板背景，避免矩形底边接缝。
- 开发门禁为 `pnpm verify`；样式与布局须在真实 Chrome 检查。Mock 或组件测试只能证明对应交互，不能证明真实模型或底座行为。
- 最新标题生成和反馈纠正的真实模型验收仍有保留项，详见变更记录；不能因界面可点击或单测通过就视为端到端完成。
