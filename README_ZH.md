# MemOS

面向 AI Agent 的记忆服务。本项目基于 [MemTensor/MemOS](https://github.com/MemTensor/MemOS)，采用 Apache-2.0 许可证。

Python 包和数据面 API 位于 `src/memos`，测试位于 `tests`。开发和验证入口见 `CONTRIBUTING.md` 与 `Makefile`。启动前请按所用环境配置存储和模型服务。

[控制面后端](https://github.com/hugegraph/MemOS/tree/be)和[管理界面前端](https://github.com/hugegraph/MemOS/tree/fe)分别维护在独立分支中。
